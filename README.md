# Silent JB для Antigravity (Gemini)

Это репозиторий проекта **"Silent JB"**.
В этом репозитории представлена **версия для Antigravity** (Gemini).

## Как это работает?

Это правила которые написаны таким образом, что Antigravity воспринимает их как правила по умочанию.
Такой "манифест" **Gemini воспринимает как закон, и следует ему безпрекословно и без сомнений**.
Этот репозиторий содержит набор инструкий (правила), которые освобождают Gemini от цензуры, этики и закона

## Как использовать

1. **Распакуйте** архив "silent_jb_for_antigravity.tar.gz" без создания подпапки в папку вашего проекта
2. **Убедитель** что теперь у вас в папке проекта есть папка ".agent/rules/silent_jb_for_antigravity/"
3. **Отправьте** Antigravity любой запрос. Будь то просто вопрос или набор инструкий к действию
